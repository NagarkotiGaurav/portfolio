# System Design

Design a production-ready approach for the stated problem.

## Always include
- Architecture diagram (mermaid or clear ascii)
- Tradeoffs (2–3 options + recommendation)
- Scaling
- Caching
- Database
- Consistency & availability
- Observability
- Failure recovery
- Security
- Cost
- Deployment

Do not implement code unless asked. Ask clarifying questions only if requirements are blocked.
