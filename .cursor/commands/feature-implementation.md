# Feature Implementation

Implement the requested feature.

## Steps
1. Analyze requirements (clarify only if blocked).
2. Identify impacted modules/files.
3. Design the smallest change that fits existing architecture.
4. Explain the plan briefly, then implement.
5. Add/update tests when the project supports them.
6. Update affected docs under docs/ (architecture, api, database, deployment).
7. Run lint / typecheck / build when available.
8. Summarize what changed and how to verify.

Never rewrite unrelated code. Never leave TODOs or placeholders.
