# API Design Review

Review the API(s) in scope (existing or proposed).

## Check
- REST resource modeling
- HTTP methods & status codes
- Validation & error shapes
- Versioning
- Pagination / filtering / sorting
- Rate limiting
- Authentication / authorization
- Idempotency (where relevant)
- Documentation completeness

## Output
- Strengths
- Issues by severity
- Concrete contract recommendations (request/response examples)
- Migration notes if a breaking change is needed
