# Performance Optimization

Optimize performance for the scoped problem.

## Check
- Database & indexes
- Caching
- Hot loops / allocations
- Memory / CPU
- Network chatter
- Bundle size / lazy loading (frontend)
- Streaming for large datasets

## Rules
- Evidence before changes (profile, measure, or justify with code paths).
- Avoid micro-optimizations.
- Prefer high-impact, low-complexity fixes.
- Report before/after expectations and residual bottlenecks.
