# Documentation Generation

Generate or update documentation for the current change or scoped area.

## Update when affected
- docs/architecture.md
- docs/api.md
- docs/database.md
- docs/deployment.md

## Rules
- Reflect actual code behavior only — do not invent APIs or flows.
- Keep docs concise, accurate, and example-driven.
- Note open questions / unknowns explicitly.
- If docs folders/files are missing, create minimal stubs then fill relevant sections.
