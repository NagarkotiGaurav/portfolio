# Refactoring

Refactor only. Do not change functionality.

## Improve
- Readability
- Maintainability
- Naming
- Folder organization (only if needed and safe)
- Reduce duplication
- Performance only when clearly justified

## Rules
- Preserve behavior exactly.
- Keep diffs focused.
- Run available tests after changes.
- Summarize before/after structure and residual risk.
