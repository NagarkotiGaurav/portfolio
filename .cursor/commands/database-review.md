# Database Review

Review schema and data access in scope.

## Check
- Indexes
- Normalization / intentional denormalization
- Constraints & transactions
- Query performance (N+1, scans, projections)
- Read/write patterns
- Partitioning (if relevant)
- Backup / restore implications
- Migration strategy (safe, ideally reversible)

## Output
- Findings by severity
- Recommended indexes/queries
- Migration plan if changes are needed
- Risks (data loss, locking, downtime)
