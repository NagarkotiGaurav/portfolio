# Growth Marketing

Run a growth marketing analysis for the current site, page, content, or scoped paths.

Respect project rules and architecture. Do not rewrite unrelated code unless explicitly asked to implement.

Load and follow the `growth-marketing` skill. Prefer the `growth-marketing-strategist` subagent for deep audits.

## Scope
1. Identify the target (live URL, routes/pages, content files, or competitor URLs). If unclear, ask once.
2. Confirm primary business goal if missing (leads, jobs, sales, authority).
3. Run only the steps that apply to the scoped request; full audits use all steps.

## Checklist (Steps 1–10)
1. Business: industry, audience, services, revenue model, competitors, value proposition
2. SEO audit: URLs, meta, headings, links, images, schema, robots, sitemap, canonicals, indexability, speed, mobile, CWV
3. Keywords: primary/secondary/long-tail, intent types, clusters, entities, LSI/NLP, low-competition opportunities
4. Content strategy: pillars, supporting pages, FAQs, case studies, blogs, landing/glossary/comparison/service/industry pages
5. AI search (GEO/AEO): What/How/Why/When/Best/Comparison/Alternatives/Cost/Examples/Checklist answer blocks, entity-rich copy, schema, LLM retrieval
6. CRO: headlines, CTA, social proof, trust, testimonials, case studies, pricing, nav, forms, lead magnets
7. Competitors: strengths, weaknesses, content/keyword/authority gaps, backlinks, SERP opportunities
8. Analytics: GA, GSC, Clarity, GTM, conversion tracking, heatmaps, funnels
9. Every recommendation: Priority, Impact, Difficulty, Expected SEO Impact, Expected Business Impact, Implementation Steps, WHY
10. Hard rules: no keyword stuffing, no generic advice, humans first, E-E-A-T, optimize for Google + AI search engines

## Output
1. Executive summary (business + top opportunities)
2. Findings by applicable step
3. Prioritized action list (P0 / P1 / P2) with Step 9 fields on each item
4. Optional: content briefs or meta drafts only when requested or clearly needed

Do not invent rankings, traffic, or backlink metrics. Base claims on evidence from the site, code, or stated data.
