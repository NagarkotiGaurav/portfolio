# Experience System

The site is an **Experience System** (digital product), not a one-off portfolio.

```text
Experience System
├── Brand System
├── Content System
├── Visual System
├── Motion System
├── Interaction System
├── Accessibility System
└── Analytics System
```

## Hierarchy
Design tokens → Foundation → Interaction patterns → Scene archetypes → Experience layer → Pages

## Experience layer (emotional journey)
Interest → Trust → Confidence → Decision → Action

## Scene archetypes
Hero · Story · Architecture · Timeline · Metrics · Proof · CTA · Gallery

Pages **compose** archetypes. Example Home: Hero → Story → Metrics → Proof → CTA.

## Interaction priority
| Priority | Examples | May compete with CTA? |
| --- | --- | --- |
| Primary | CTA, Hero, Nav | — |
| Secondary | Cards, Timeline | Carefully |
| Tertiary | Chips, icons | No |
| Ambient | Noise, orb, grid | Never |

## Trust system
Every page shows ≥ 1 trust signal (metrics, process, architecture, availability, work, etc.).

## Responsive narrative
Mobile may reorder beats (e.g. Metrics before Architecture). Document per page when diverging.
